# 跨平台功能对照

本表以各 Minecraft 版本对应的 Fabric 源码为功能基准，逐项核对非 Fabric 实现。现代 Forge/NeoForge 通过同版本 Fabric 源码的业务逻辑副本实现，包名、配置类名、运行时类名和加载器入口属于平台适配差异。

完整的 30 项功能清单、版本矩阵和逐项入口对照见 [`FABRIC_FORGE_FUNCTION_CHECKLIST.md`](FABRIC_FORGE_FUNCTION_CHECKLIST.md)。

## 核对结果

- Forge 1.20.1、Forge 1.20.4、NeoForge 1.21.1 的 Java 业务文件，与各自同版本 Fabric 文件做包名和平台类名归一化后无差异。
- 三个现代非 Fabric 版本的三套语言资源均为 204 个键，键集合和值完全一致；旧版 Forge 1.8.9、1.12.2 的三套语言资源也已补齐到同样的 204 个键。
- 现代非 Fabric Mixin 配置保留对应 Fabric 的全部通用入口，并额外加载器 Mixin 处理手持物品名称；旧版 Forge 使用独立 ASM 注入，不能直接复用现代 Mixin。
- Forge 1.20.1、1.20.4 的 F3 文本由 `ForgeGui.renderHUDText` 直接绘制，已增加 ForgeGui 专用抑制上下文；原版调试 HUD 和 FPS/网络图表仍由 `DebugHudMixin` 保护，避免 F3 文本被翻译。
- 旧版 Forge 已补齐 I 键日志和配置字段；其不能等价支持现代 TextDisplay 玩家跟随特例，也不能可靠区分玩家聊天与系统消息，这是旧版 API 的明确限制。
- 1.16.5 的 Fabric 端界面按该版本 API 实现（`MatrixStack`、`Screen#onClose`/`isPauseScreen`、
  `TextFieldWidget`、`ButtonWidget.TooltipSupplier`），功能与 1.21.x 对齐，但没有 `TextDisplay`，
  因此与旧版 Forge 使用同一口径：保留通用字体翻译，不伪造玩家跟随特例。
- 1.18.1 的 Fabric 端以 1.17.1 为移植基线（同为 Java 17、单一 `src/main` 源集），按该版本 API 把
  `Screen#isPauseScreen` 改为 `shouldPause`，全部 16 个 Mixin 的注入目标与 `@Shadow` 字段已对照
  映射后的 1.18.1 类文件核对；功能与 1.17.1 对齐，且因 1.18 没有 `TextDisplay` 而采用与旧版
  Forge 相同的口径。
- 1.21.4、1.21.11、26.1、26.2 已按已确认的 Forge/NeoForge 坐标建立工程；源码与 Mixin 集合已逐文件对照，实机启动验收仍待完成。
- 26.3 只有 Fabric 端，没有对应加载器可对照，因此不参与本表的 Fabric/非 Fabric 差异判定。
- 高版本坐标记录为 Forge `1.21.4-54.1.18`、`1.21.11-61.2.1`、`26.1.2-64.1.3`、`26.2-65.1.3`，NeoForge `21.4.157`、`21.11.45`、`26.1.2.100`、`26.2.0.75`。

## 同步顺序

后续新增平台时按以下顺序逐项验收：

1. 配置字段、迁移和所有 provider 页面。
2. U/F8/I 三个入口及本地 UI 防二次翻译。
3. 聊天、玩家回显、系统消息和断线处理。
4. 标题、字幕、动作栏、Boss 栏及异步失败回退。
5. 书本、告示牌、tooltip、Lore、内置贴图和换行布局。
6. 计分板、玩家列表、调试信息、实体名、手持物品名。
7. 全息文本、加载器 Mixin、语言资源、产物内容和实际启动检查。
